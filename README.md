# Baltazar

Baltazar is an Android application developed with Kotlin and Jetpack Compose, following Clean Architecture principles.

## Project Structure

- **app**: Main application module.
- **data**: Implementation of repositories and data sources (Network, Local DB).
- **domain**: Business logic, UseCases, and Repository interfaces.
- **core**: Common utilities, dependency injection, and base classes.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: Clean Architecture + MVVM
- **Dependency Injection**: Hilt (planned)
- **Networking**: Retrofit (planned)

## Getting Started

1. Clone the repository.
2. Open with Android Studio.
3. Build and run the app.
